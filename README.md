# Fill Type Tooltips – FS25

In the shop, trailers and tools only show small icons for the fill types they can carry, without any text.
With this mod, **hover the mouse over a fill type icon** and a small tooltip shows the name of the fill type.

![icon](icon_preview.png)

## Features
- Small tooltip next to the mouse with the fill type name (e.g. *Wheat*, *Potatoes*, *Silage*)
- Works in the shop and in the other menus that show fill type icons
- Names come from the game itself, so they appear in your game language
- No keys, no settings: just hover

## Install
Download **FS25_FillTypeTooltips.zip** from the [latest release](../../releases/latest) and put it in your `mods` folder. Do not unzip it.

## Info
- Game: Farming Simulator 25
- Multiplayer supported
- Languages: English, German, French (fill type names follow the game language)
